# MEEBAN + Firebase Firestore

โปรเจกต์นี้ต่อ Cloud Firestore ให้กับระบบเดิมโดยคงหน้าตาและฟังก์ชันเดิมไว้

## เปิดใช้งาน
1. แตก ZIP
2. เปิดโฟลเดอร์นี้ใน VS Code
3. เปิด `index.html` ด้วย Live Server
4. Login ด้วย `admin / 1234`

## Firebase
ค่า Firebase Config อยู่ใน `js/firebase.js` เรียบร้อยแล้ว

ข้อมูลหลักจะเก็บใน Firestore ดังนี้:
- `rooms`
- `tenants`
- `bills`
- `payments`
- `settings/main`
- `dormInfo/main`
- `moveInFees/main`
- `meta/main` (ใช้ระบุสถานะการเริ่มต้นฐานข้อมูล)

ระบบยังเก็บ LocalStorage เป็น cache เพื่อให้หน้าเว็บไม่พังระหว่างที่ Firebase กำลังโหลดหรือมีปัญหาการเชื่อมต่อ แต่เมื่อ Firestore พร้อม ข้อมูลจะถูกอ่านจาก Firestore และการบันทึกจากปุ่มเดิมจะ sync ขึ้น Firestore อัตโนมัติ

## หมายเหตุเรื่อง Rules
สำหรับการทดสอบในเครื่อง Firestore ต้องอนุญาตให้เว็บอ่าน/เขียนข้อมูลได้ หาก Rules เป็น Public ตามที่ตั้งไว้ใน Firebase Console ตอนนี้ ระบบสามารถเชื่อมและบันทึกข้อมูลได้

Rules แบบ Public ไม่ควรใช้บนระบบจริงโดยไม่มีการรักษาความปลอดภัยเพิ่มเติม


### รูปภาพห้อง
รูปภาพจะถูกบีบอัดฝั่งเบราว์เซอร์ก่อนบันทึกลง Firestore เพื่อไม่ให้เอกสารเกินขนาด 1 MiB ของ Firestore


## Record IDs
- ห้องพักใช้ ID รูปแบบ `ROOM-...`
- ผู้เช่าใช้ ID รูปแบบ `TENANT-...`
- บิลใช้ ID รูปแบบ `BILL-...`
- การชำระเงินใช้ ID รูปแบบ `PAY-...`
- ID เดิมจะไม่เปลี่ยนเมื่อแก้ไขข้อมูล
- ID ที่แสดงบนการ์ดคือ Firestore Document ID และมีปุ่มคัดลอก
- การค้นหาห้องและผู้เช่าสามารถค้นด้วย ID ได้
- ตอนลบระบบจะแสดง ID ในกล่องยืนยัน เพื่อป้องกันลบผิดรายการ
